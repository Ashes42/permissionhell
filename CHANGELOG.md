# Changelog

Milestone history; historical release dates have not been reconstructed.

- **1.6.0 — Release hardening:** explicit packaging metadata and dev tools, CLI
  examples, Ubuntu CI, isolated wheel/build checks, schema/architecture/security
  documentation and a concise installation-first README. Format versions unchanged.
- **1.5.0 — Monitoring:** one-shot baseline initialization, comparison and explicit
  atomic updates for account/process snapshots; optional text churn filtering.
- **1.4.0 — LSM awareness:** AppArmor/SELinux context and conservative confidence,
  propagated through process audits, policy, graphs and snapshots.
- **1.3.0 — Snapshots/diff:** portable observations, safe publication and offline
  identity-aware comparisons.
- **1.2.0 — Policy drift:** explicit JSON intentions compared with effective models.
- **1.1.0 — Access graph:** text, JSON and DOT projections of collected diagnoses.
- **1.0.0 — Process audit:** visible-process/resource inventories and summaries.
- **0.9.0 — Namespaces:** namespace-aware process identity mapping.
- **0.8.0 — Capabilities:** supported effective DAC capability overrides.
- **0.7.0 — Process analysis:** live proc filesystem credentials and context.
- **0.6.0 — JSON:** structured diagnostic output.
- **0.5.0 — Remediation suggestions:** informational change alternatives, never applied.
- **0.4.0 — Focused explain:** ordered access-path explanations for one audit subject.
- **0.3.0 — Account audit:** local account inventory and concise grouped output.
- **0.2.0 — POSIX ACL:** access ACL selection and mask reasoning.
- **0.1.0 — DAC engine:** exclusive permission classes, traversal, mount restrictions
  and explanations.
